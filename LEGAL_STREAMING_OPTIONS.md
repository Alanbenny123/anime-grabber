# Streaming links and playback scope

AnimeGrabber is a discovery site. It does not host or play full episodes. The title page embeds a YouTube trailer when Jikan supplies a valid YouTube ID and shows HTTPS streaming links returned in the title's Jikan data. Link availability depends on the provider and the visitor's region.

The app does not construct episode URLs, embed third-party episode pages, or maintain a list of alternative streaming sites. Adding full episode playback would require an appropriate source and permission to use it. Review any new provider integration and the site's public claims before deployment.

See [ANIME_API_INTEGRATION.md](ANIME_API_INTEGRATION.md) for the current data flow.
