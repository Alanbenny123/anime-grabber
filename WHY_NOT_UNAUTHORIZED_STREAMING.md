# Why the app does not embed episode sites

The application has no verified episode source or playback rights. Guessing a provider URL from a title and episode number was unreliable: titles vary between catalogs, provider URLs change, and some sites block embedding.

The current detail page therefore shows Jikan metadata, a trailer when available, and HTTPS streaming links listed for the title. Any future episode source should be reviewed for reliability, security, and permission before it is added.
